🔗 URL Shortener

A backend URL Shortener REST API built with Java, Spring Boot, MongoDB, and REST APIs.
The project provides APIs to create short URLs, retrieve the original URL using a short URL, and delete shortened URLs.

🚀 Features

Create a shortened URL

Retrieve the original URL using a short URL

Delete a shortened URL

MongoDB persistence

Input validation using Jakarta Bean Validation

Custom exception handling

Global exception handling

Swagger / OpenAPI API documentation

Request tracing with MDC

Logging using SLF4J / Lombok

Unique short URL validation at the database level
